# Python Security Projects

A collection of beginner security tools built while learning Python, 
each one introducing a new core concept.

| Project | Concepts |
|---|---|
| [Password Strength Checker](./password-strength-checker) | String/regex logic, boolean conditions |
| [Password Generator](./password-generator) | `secrets` module, cryptographic randomness |
| [File Integrity Checker](./file-integrity-checker) | `hashlib`, file I/O, JSON persistence |
| [Port Scanner](./port-scanner) | `socket`, TCP/IP, threading |
| [Domain Lookup Tool](./domain-lookup-tool) | DNS resolution, WHOIS|

Each project has its own README with details on how it works and what 
it taught me.
